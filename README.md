# AI From Zero

Un parcours francophone pour partir de **zéro connaissance informatique** et arriver à la conception expérimentale de son propre modèle d'intelligence artificielle.

## Principe
On apprend en construisant. Aucun Transformer préfabriqué n'est utilisé pour cacher les mécanismes fondamentaux. Le même laboratoire évolue progressivement : Python → réseau neuronal → tokenizer → modèle de langage → Transformer → Transformer moderne → optimisation → MoE → SSM/Mamba → multimodal → mémoire/raisonnement → architecture personnelle.

## Site
Le site statique est dans `index.html` et `assets/`, compatible GitHub Pages. La progression est conservée localement dans le navigateur.

## Cours
Le plan maître et les dépendances pédagogiques sont dans `docs/CURRICULUM.md`.

## Modèle
Le code évolutif vivra dans `model/`. Chaque composant doit rester interchangeable et testable.

## Règle
Si une leçon emploie une notion qui n'a pas été enseignée auparavant, c'est un bug pédagogique.
