# Curriculum — AI From Zero

## Règle pédagogique
Aucune notion ne doit être utilisée avant d'avoir été introduite, expliquée, illustrée et pratiquée. Chaque module contient : intuition → vocabulaire → visualisation → théorie → code → expérience → exercice → quiz → checkpoint.

## Objectif final
Être capable de concevoir, programmer, entraîner, évaluer, profiler et faire évoluer un modèle d'IA modulaire, puis comparer expérimentalement des architectures alternatives.

## Dépendances
0. Fondations : ordinateur, terminal, fichiers, Python, Git, environnement, nombres, fonctions, vecteurs, matrices, probabilités et dérivées intuitives.
1. ML : dataset, paramètres, neurone, réseau, forward pass, loss, gradient, backpropagation, optimiseur.
2. Représentation : texte, corpus, Unicode, tokenisation, vocabulaire, embeddings.
3. Langage : next-token prediction, contexte, logits, softmax, cross-entropy, sampling, entraînement d'un mini modèle.
4. Transformer : Q/K/V, self-attention, masque causal, multi-head, résiduel, normalisation, FFN.
5. Moderne : RMSNorm, RoPE, SwiGLU, GQA/MQA, KV cache.
6. Efficacité : mémoire, complexité, profiling, mixed precision, quantification, batching.
7. MoE : experts, router, top-k, load balancing.
8. SSM/Mamba : état, récurrence, scan, sélectivité, hybride attention/SSM.
9. Multimodal : encodeurs, projections, représentations image/audio/vidéo, fusion.
10. Mémoire/raisonnement : mémoire externe, retrieval, récurrence et calcul adaptatif.
11. Recherche : architectures émergentes et lecture critique de papiers.
12. Architecture personnelle : ablations, benchmarks, compromis qualité/latence/RAM et conception expérimentale.

## Validation finale
Le parcours n'est terminé que si l'apprenant peut expliquer chaque composant, le coder, le tester, mesurer son coût, le remplacer et justifier ses choix.
