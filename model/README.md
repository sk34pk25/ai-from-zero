# Modèle évolutif

Le code du modèle sera construit progressivement pendant le cours. Les interfaces resteront séparées afin de pouvoir remplacer les composants sans réécrire le projet : données/tokenizer, embeddings, backbone, mémoire, head de sortie, entraînement, évaluation et génération.

Le premier modèle sera volontairement minuscule. Les étapes suivantes feront évoluer le même laboratoire vers Transformer moderne, MoE, SSM/Mamba, multimodal et architectures expérimentales.
