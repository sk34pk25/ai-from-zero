# Relire le parcours sur le terrain

Ce protocole est prêt à utiliser. Aucune session avec un débutant ni aucun appareil physique n'est déclaré testé par ce document.

## Essai avec un débutant

Prévoir deux ou trois volontaires avec leur accord. Utiliser un alias, sans adresse, identifiant, mot de passe ou donnée sensible. Rien n'est envoyé automatiquement.

1. Partir de l'accueil dans un navigateur neuf ; distinguer lecture seule et suivi local.
2. Faire le positionnement, puis le programme personnel. Conserver aussi erreurs, temps réel et abandons.
3. Reconstruire le mini-projet 0.23 sans corrigé ; demander un cas nouveau (négatifs, lignes vides, seuil égal à une valeur).
4. Suivre le tronc commun à son rythme jusqu'au projet final. Séparer lecture, programmation et recherche d'erreurs.
5. Demander des explications avec d'autres nombres et une modification du code ; relever les aides.
6. Relire le projet avec PROJET_FINAL.md. Les contrôles publics ne certifient pas l'autonomie.

Tester deux onglets : terminer deux leçons différentes, décocher, fermer et rouvrir ; effacer dans un onglet et vérifier l'autre. Vérifier que le stockage refusé laisse lire le cours. Exporter avant d'effacer si l'on veut conserver ses données.

Les TP locaux nécessitent Python/NumPy sur un environnement approprié. La lecture sur tablette ne rend pas les commandes système disponibles.

## Observer la nouvelle lecture

Partir du mode guidé d’un navigateur neuf. Observer si la personne comprend les fondations avant de répondre, puis lui faire expliquer la différence avec la révision visuelle. Relire aussi DOSSIER_MODELE.md rempli sur un corpus nouveau. Aucun résultat de terrain n’est prérempli.
